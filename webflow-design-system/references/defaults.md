# Default Templates

Two ready-to-use design system templates. Applied when:
- User explicitly asks for defaults or a template
- User skips value entry in Starter mode
- Developer Excel is pushed with empty Value cells

## Applying Defaults

**When to apply:**
- User says "use defaults", "use template", "I'm not sure", or leaves a value blank
- Apply the selected flavor's value for that token silently
- Note in the preview summary which values came from the template vs user-provided

**How to note in preview summary:**
```
• color-primary: #2563EB  ← from Modern Minimal template
• color-secondary: #9B59B6  ← your value
```

This keeps the user informed and makes it easy to spot what they may want to change later.

**In Developer Excel:**
- Pre-fill the Value column with the selected flavor's defaults
- User only needs to override what they want to change
- Template-sourced values get a light yellow cell background to distinguish them from user entries
